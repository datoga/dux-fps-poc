# Dux privacy notice

Last updated: 15 October 2026

Dux lets you turn an image into a shareable browser game. This project is an early release; before public launch, replace this notice with the operator's legal name, contact details, hosting providers, and the final production URL.

## Images and games

Image resizing and pixel conversion happen in your browser. Dux receives only the final 128 × 128 texture and uses it to build the game package. It does not receive the original image through the game API. If you choose an image from ChatGPT or use ChatGPT's file upload, that file is handled by ChatGPT under its own terms and privacy controls.

The final texture and the game package are stored by the Dux server and are publicly accessible to anyone with the share link for seven days. They are then removed automatically. Do not upload images you do not have permission to share, private or sensitive images, or information you would not want to be public. Dux does not currently offer an account or an immediate self-service deletion feature.

## Logs and technical data

Dux does not currently use accounts, advertising cookies, or analytics. The server writes standard request logs, which may contain an IP address, requested path, and request time. When hosted, the infrastructure provider may also create operational and security logs according to its own retention policy.

## Your choices

You can avoid publishing an image by closing the creator before choosing “Crear partida.” Once published, the texture is public through the share link and retained for up to seven days. For privacy requests, contact the operator listed on the production website; contact details must be added before public launch.

## Changes

This notice must be reviewed and updated when Dux adds accounts, payments, analytics, moderation, or a different storage provider.
